Las variables CDS/ADS/EWDS/CDSE se reservan y documentan para el acceso; no se declara implementado un conector por tenerlas en el ejemplo. Ningún script crea cuentas, acepta términos ni activa servicios pagos.

Acceso sin cuenta comprobado con datos: ERDDAP CRW (SST, HotSpot, DHW), USGS FDSN/OAF, SWPC observado/previsto, MODIS ORNL (subconjuntos locales), ECMWF Open Data IFS, NCEI OISST, CNEOS Sentry, CPC ONI, CAP de NTWC/PTWC, Smithsonian GVP, NOAA PSL MHW, NASA LHASA y GLO-90 público en AWS. GVP usa `webservices.volcano.si.edu/geoserver/GVP-VOTW/ows`; el 403 inicial correspondía a otro host. La primera prueba FIRMS fue Suomi NPP, cuya ficha oficial indica fin de cobertura 02/11/2026: su CSV vacío no bloquea NOAA-20. Se resolvió el índice oficial y se ingirió NOAA-20/Sudamérica con 15.977 detecciones, cotejadas contra SHP, sin MAP_KEY. [Ficha oficial VIIRS](https://firms.modaps.eosdis.nasa.gov/content/descriptions/FIRMS_VIIRS_Firehotspots.html).

D30 ya dispone de una tesela GLO-90 pública sin cuenta AWS/CDSE. Las credenciales CDSE de la tabla corresponden a otras rutas de descarga y a Sentinel, no bloquean esa tesela. D24 y D16 usan rangos HTTPS conservados y comprobados; no descargan las colecciones completas. El formulario [RAPID](https://rapid.ac.uk/data/data-download), D34, pide correo, pero el proveedor también publica una [ficha con URL directa](https://rapid.ac.uk/rapidtransportsv2024-2nc) y su política de datos abiertos. Se comprobó y descargó el NetCDF v2024-2 de 7,05 MB por esa vía pública, sin enviar información personal, crear cuenta ni aceptar formularios. AMOC, calor y agua dulce mensuales ya funcionan; no requieren variables de credencial.

La documentación de [ECMWF Open Data](https://www.ecmwf.int/en/forecasts/datasets/open-data) publica un subconjunto gratuito por HTTPS, bajo CC BY 4.0 y términos ECMWF: no necesita cuenta CDS para esa distribución. La historia ERA5 y los ensembles estacionales siguen siendo vías diferentes.

La confianza TLS usa el almacén de certificados del sistema mediante `truststore`. No se desactiva la comprobación de certificados. Los resultados de descubrimiento no cuentan como productos integrados.

También comprobados sin cuenta: IBTrACS NCEI, CAP GDACS, subconjuntos GEBCO con TID, ASIS FAO F32, reportes RAMSES y BasinATLAS v1 nivel 03 (HydroATLAS) vía Figshare. Este último usa sólo cuatro miembros del ZIP, con licencia CC BY 4.0; una redirección pública puede expirar y se renueva una vez si el error declara `ExpiredRequest`, sin credenciales.

D25 tiene además un campo científico público real: [Sentinel-3A OLCI OC4Me L3 en NOAA CoastWatch](https://coastwatch.noaa.gov/erddap/info/noaacwS3AOLCIchlaDaily/index.html), Copernicus, estado Experimental y atribución obligatoria «Contains modified Copernicus Sentinel data». El 14/11/2026 se repitió la consulta acotada de SMAP en ORNL: el catálogo sí enumera `SPL3SMP_E`, pero `dates` devolvió HTTP 400 «No SPL3SMP_E data available» para Pampa y para el ejemplo norteamericano 35,98° N / 79,10° O. La [distribución IMERG GIS](https://gpm.nasa.gov/data/directory/imerg-early-run-pps-near-real-time-gis) exige además registro PPS si se elige esa ruta; no se confunde con acceso Earthdata/GES DISC ni se declara un cliente PPS implementado. D11: se comprobó acceso público GWIS a TIFF Float32, no sólo PNG. Sin embargo, la salida no distingue cero físico de fondo oceánico, carece de nodata/máscara científica y no acredita emisión/ciclo. Dos recortes nominalmente alineados discreparon; causa no resuelta. WCS no expone `ecmwf.fwi`. Evidencia y archivos originales pequeños en [data/samples/d11-gwis](../data/samples/d11-gwis/README.md); se mantiene no integrado. No se pide una credencial ficticia para esa URL pública. Se necesita el producto nativo calificado o resolver la distribución con el proveedor; una [solicitud manual](https://forest-fire.emergency.copernicus.eu/apps/data.request.form/) puede ser necesaria. Según [CEMS](https://confluence.ecmwf.int/spaces/CEMS/pages/382667784/CEMS-Fire+Data+access), tiempo real GWIS/EFFIS e historia/estacionales EWDS son vías diferentes. Las variables EWDS de arriba no equivalen a acceso al forecast en tiempo real.

Doble decodificación, Kelvin, UTC/CF y georreferenciación comprobados; no ERA5T ni una serie histórica completa. La [ficha oficial ERA5](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=overview) identifica licencia CC-BY y DOI. El enlace antiguo de licencia en el README ARCO devuelve 404; se conserva la ficha vigente y la atribución. El conector CDS autenticado y las otras colecciones siguen siendo rutas distintas.

D33: el [archivo global NASA/NDMC](https://nasagrace.unl.edu/GlobalData.aspx?p=current), enlazado por Drought.gov, publica NetCDF y tres TIFF científicos sin cuenta. Descargados/cotejados completos, edición 030, referencia CF 10/11/2026: percentiles de agua subterránea somera, zona radicular y humedad superficial. No requieren variables Earthdata en esta distribución. Se conserva una copia exacta compartida de 4,86 MB; NetCDF y TIFF coinciden en valores/máscaras. No es humedad volumétrica ni lectura de un pozo. El input nativo termina en 2019-08 y no acredita fecha de última observación satelital incorporada; se muestra esa limitación. El forecast CONUS de 30/60/90 días y otras colecciones/formatos siguen siendo productos distintos.

D01 tiene una distribución histórica pública diferente del acceso reciente: la [climatología mundial IMERG Final V07B](https://gpm.nasa.gov/data/imerg/precipitation-climatology), junio 2000–mayo 2023. No se convierte en probabilidad ni en riesgo de V. parahaemolyticus en ostras. Sus metadatos se conservan como evidencia de descubrimiento, no como integración.
