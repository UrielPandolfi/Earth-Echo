# D18 HABSOS: acceso real, calificación científica pendiente

El [producto NOAA/NCEI HABSOS](https://www.ncei.noaa.gov/products/harmful-algal-blooms-observing-system) publica recuentos biológicos de Karenia brevis por [REST oficial](https://gis.ncdc.noaa.gov/arcgis/rest/services/ms/HABSOS_CellCounts/MapServer/0). Se retuvieron metadatos y sólo diez últimas muestras, no la colección. Unidades cells/L, especie explícita; esta muestra tiene diez ceros reales, no datos ausentes rellenados. JSON contiene coordenadas WGS84 y latitud/longitud originales por separado. URLs, fechas de recuperación, bytes y SHA en `evidence.json`.

No se publica como ScientificProduct ni se suma D18 a fuentes conectadas: CELLCOUNT_QA=1 en las diez filas, pero campo entero sin dominio/catálogo de códigos; no se pudo acreditar su semántica. No se importa la convención de otro producto para llamarlo «bueno». Metadata de capa vacía retenida como evidencia; no código de calidad documentado. SAMPLE_DATE está serializado en milisegundos ArcGIS, sin timeInfo/dateFieldsTimeReference; eso no prueba por sí solo cómo se convirtió la hora original de colección.

También se consultaron páginas oficiales de método/NCCOS y código público del visor, sin ejecutar scripts remotos. No resolvieron esas definiciones. La [vía de forecast enlazada por NCCOS](https://coastalscience.noaa.gov/science-areas/habs/hab-forecasts/gulf-coast/faqs/) en habforecast.gcoos.org devolvió conexión rechazada, no una respuesta numérica. No se convierte una muestra biológica en probabilidad/toxicidad, riesgo respiratorio, hipoxia o pronóstico de Vibrio. Estos bloqueos no requieren inventar variables de credencial ni crear cuenta; hacen falta disponibilidad del servicio y definición oficial del producto.
