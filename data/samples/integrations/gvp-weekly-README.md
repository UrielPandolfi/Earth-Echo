# Muestra original de reportes GVP

Dos reportes (Krakatau/Manam) extraídos de los RSS y CAP 1.1 oficiales, sin cambiar sus datos. XML reserializado UTF-8; el activo de producción conserva ambos originales ISO-8859-1 íntegros por base64. Emisión por ítem/CAP: 15/10/2026 07:11:08 UTC, período local textual 8–14 octubre. Canal RSS declara una zona con una hora de diferencia, que se conserva como tal.

No representa actividad actual ni pronóstico. Smithsonian Global Volcanism Program / USGS Volcano Hazards Program; fuentes primarias nativas en cada reporte. https://volcano.si.edu/news/WeeklyVolcanoRSS.xml y https://volcano.si.edu/news/WeeklyVolcanoCAP.xml.
