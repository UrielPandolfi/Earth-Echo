# Muestra científica original RAPID

Arrays completos de 248 medias mensuales time_1m, amoc_depth_1m, heat_trans_1m y frwa_trans_1m extraídos sin modificar valores del producto RAPID_transports_v2024-2.nc (7.050.022 bytes), descargado desde la URL oficial https://rapid.ac.uk/sites/default/files/rapid_data/data/RAPID_transports_v2024-2.nc. Se conservaron atributos de unidad/calendario/versión/DOI; el HDF5 pequeño de prueba tiene offsets nuevos, no pretende ser el NetCDF completo. El original íntegro se conserva en el almacén científico y se comparte entre las tres series.

Transporte integrado en la sección del Atlántico 26,5° N: AMOC y agua dulce en Sv, calor en PW; signo positivo norte. Son datos procesados abril 2004–noviembre 2024, no pronóstico ni índice mundial. NaN es ausencia. Las estadísticas publicadas de la misma edición se guardaron como extracto factual separado para el cotejo independiente.
